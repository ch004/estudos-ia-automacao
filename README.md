# Estudos: IA e Automação Digital

Repositório com as anotações e os exercícios do meu curso de **Tecnologia em Inteligência Artificial e Automação Digital** (UniFECAF), que cursei em paralelo com o trabalho em suporte técnico.

## Estrutura
- `1o-semestre/`: Algoritmos e Lógica de Programação, Padrões Web para No-Code/Low-Code, Banco de Dados Visual, Gestão de Projetos, Fundamentos de IA Generativa, Fundamentos de No-Code/Low-Code
- `2o-semestre/`: UX/UI, Aplicações Web Low-Code, IA Generativa aplicada ao desenvolvimento, Integração de APIs, Metodologias Ágeis
- `3o-semestre/`: Automações com Low-Code, Automação de Processos e Workflows, IA Generativa avançada, Infraestrutura e Segurança

Cada pasta de semestre terá uma pasta por disciplina, com exercícios e anotações.
